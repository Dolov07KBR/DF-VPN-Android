# DF VPN for Android

DF VPN — Android-клиент подписок на базе открытого проекта [v2rayNG](https://github.com/2dust/v2rayNG).

Поддерживаются импорт подписок и отдельных конфигураций, VLESS/Reality, VMess, Trojan, Shadowsocks и другие протоколы, поддерживаемые Xray-core. Русский интерфейс уже входит в upstream.

## Лицензия и авторство

Проект является производной работой v2rayNG и распространяется по GPL-3.0. Исходная история, LICENSE и сведения об авторах сохранены. DF VPN не является официальным приложением v2rayNG или Happ.
